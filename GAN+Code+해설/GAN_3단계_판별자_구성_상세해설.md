# 3단계. GAN 판별자(Discriminator) 구성 코드 상세 해설

## 1. 판별자의 역할

**판별자(Discriminator, D)**는 입력된 손글씨 숫자 이미지가 실제 MNIST 데이터인지, 생성자(Generator, G)가 만든 가짜 이미지인지 구분하도록 학습하는 신경망이다.

- **생성자 G:** 무작위 잠재벡터를 이용해 가짜 손글씨 이미지를 생성한다.
- **판별자 D:** 입력 이미지가 실제 데이터에서 왔을 것으로 판단하는 정도를 0~1 사이의 값으로 출력한다.
- 판별자는 **숫자가 3인지 8인지 분류하는 모델이 아니다.** 진짜와 가짜를 구분하는 이진 분류 모델이다.

## 2. 판별자 구성 코드

```python
class Discriminator(nn.Module):
    def __init__(self):
        super(Discriminator, self).__init__()

        self.model = nn.Sequential(
            nn.Linear(28 * 28, 512),
            nn.LeakyReLU(0.2),

            nn.Linear(512, 256),
            nn.LeakyReLU(0.2),

            nn.Linear(256, 1),
            nn.Sigmoid()
        )

    def forward(self, img):
        img_flat = img.view(img.size(0), -1)
        validity = self.model(img_flat)
        return validity
```

## 3. 판별자 신경망 구조

| 단계 | 입력 | 출력 | 역할 |
|---|---:|---:|---|
| 이미지 입력 | 28×28 | 784 | 픽셀값을 일렬로 펼침 |
| 은닉층 1 | 784 | 512 | 특징 표현 계산 |
| 은닉층 2 | 512 | 256 | 특징을 재조합하여 판별 정보 구성 |
| 출력층 | 256 | 1 | 판별 점수 계산 |
| Sigmoid | 실수 | 0~1 | 진짜로 판단하는 정도를 출력 |

생성자는 `100 → 256 → 512 → 1024 → 784`의 구조이고, 판별자는 `784 → 512 → 256 → 1`의 구조이다. 두 모델은 서로 반대되는 목적을 갖지만 완전히 대칭인 구조는 아니다.

## 4. 코드별 상세 해설

### 4.1 판별자 클래스 정의

```python
class Discriminator(nn.Module):
```

`nn.Module`을 상속하여 판별자 신경망의 층과 학습 가능한 가중치를 관리한다.

```python
def __init__(self):
    super(Discriminator, self).__init__()
```

객체 생성 시 부모 클래스의 초기화 기능을 실행한다.

### 4.2 첫 번째 은닉층: 784 → 512

```python
nn.Linear(28 * 28, 512),
nn.LeakyReLU(0.2),
```

28×28 흑백 이미지의 784개 픽셀값을 받아 512개 특징값으로 변환한다.

$$
h_1=\operatorname{LeakyReLU}(W_1x+b_1)
$$

- $x$: 입력 이미지의 784개 픽셀값
- $W_1$: 학습되는 가중치 행렬
- $b_1$: 편향
- $h_1$: 512개 은닉층 출력값

**예시:** 숫자 8처럼 보이는 이미지를 입력하면, 여러 픽셀의 관계를 조합하여 획의 연결, 곡선 형태, 밝기 분포 등 판별에 유용한 특징을 표현할 수 있다. 특정 뉴런 하나가 반드시 특정 획 하나를 담당하는 것은 아니다.

### 4.3 두 번째 은닉층: 512 → 256

```python
nn.Linear(512, 256),
nn.LeakyReLU(0.2),
```

첫 번째 은닉층의 512개 특징값을 256개로 변환한다.

$$
h_2=\operatorname{LeakyReLU}(W_2h_1+b_2)
$$

이 층은 앞선 특징들을 다시 조합하여 실제 손글씨와 생성 이미지의 차이를 판별하는 데 필요한 표현을 계산한다.

### 4.4 출력층: 256 → 1

```python
nn.Linear(256, 1),
nn.Sigmoid()
```

256개 특징값을 하나의 판별 점수로 변환하고, Sigmoid 함수로 0~1 범위에 맞춘다.

$$
a=W_3h_2+b_3
$$

$$
D(x)=\frac{1}{1+e^{-a}}
$$

## 5. Sigmoid 함수의 의미

| 판별값 $D(x)$ | 해석 |
|---:|---|
| 0.95 | 실제 이미지라고 강하게 판단 |
| 0.80 | 실제 이미지라고 비교적 강하게 판단 |
| 0.50 | 진짜와 가짜를 뚜렷하게 구분하지 못함 |
| 0.20 | 가짜 이미지라고 비교적 강하게 판단 |
| 0.05 | 가짜 이미지라고 강하게 판단 |

**주의:** 판별값 0.95는 숫자 9를 95% 확률로 인식했다는 뜻이 아니다. 입력 이미지가 실제 데이터에서 왔다고 판별하는 정도이다. 이 값이 현실의 정확한 확률로 보정되어 있다는 보장도 없다.

## 6. `forward()` 함수의 작동 원리

```python
def forward(self, img):
    img_flat = img.view(img.size(0), -1)
    validity = self.model(img_flat)
    return validity
```

1. `img.view(img.size(0), -1)`은 이미지를 일렬로 펼친다.
2. `self.model(img_flat)`은 펼쳐진 이미지의 진짜·가짜 판별값을 계산한다.
3. `return validity`는 계산한 판별값을 반환한다.

**128장 배치의 예시:**

```text
입력 이미지:       (128, 1, 28, 28)
이미지 펼치기:     (128, 784)
판별자 출력:       (128, 1)
```

여기서 `-1`은 다른 차원에 맞춰 필요한 크기를 자동으로 계산하라는 뜻이다.

## 7. 판별자의 학습 방법

| 입력 | 정답 레이블 | 학습 목표 |
|---|---:|---|
| MNIST 실제 이미지 | 1 | 판별값을 1에 가깝게 |
| 생성자가 만든 이미지 | 0 | 판별값을 0에 가깝게 |

**학습 예시:** 실제 숫자 3을 입력했을 때 0.9를 출력했다면 정답 1에 가깝다. 반면 생성자가 만든 가짜 숫자 8에 0.8을 출력했다면, 정답 0과 크게 달라 판별 오차가 크다.

판별자는 이 오차를 줄이도록 역전파로 기울기를 계산하고 Adam으로 가중치를 수정한다.

## 8. 손실함수: 이진 교차 엔트로피(BCELoss)

$$
L=-\left[y\ln(p)+(1-y)\ln(1-p)\right]
$$

- $L$: 손실값
- $y$: 정답 레이블(0 또는 1)
- $p$: 판별자의 출력값
- $\ln$: 자연로그

**예시 1: 실제 이미지의 정답이 1이고 판별값이 0.9일 때**

$$
L=-\ln(0.9)\approx0.105
$$

**예시 2: 실제 이미지의 정답이 1인데 판별값이 0.2일 때**

$$
L=-\ln(0.2)\approx1.609
$$

잘못 판단할수록 손실이 커진다. 실제 이미지와 가짜 이미지 각각에 대한 손실을 이용하여 판별자를 학습한다.

## 9. 판별자의 학습이 생성자에게 미치는 영향

판별자의 역할은 진짜·가짜 판별뿐 아니라 **생성자가 개선될 수 있도록 미분 가능한 학습 신호를 제공하는 것**이다.

1. 생성자가 무작위 잠재벡터로 가짜 숫자 이미지를 생성한다.
2. 판별자가 생성 이미지에 대해 판별값을 출력한다.
3. 생성자는 판별자가 가짜 이미지를 진짜로 판단하도록 손실을 계산한다.
4. 판별자를 통과한 계산 그래프를 통해 생성자의 가중치에 대한 기울기를 역전파한다.
5. Adam이 생성자의 가중치를 수정한다.
6. 이를 반복하면서 생성자는 더 그럴듯한 이미지를 만들도록 학습한다.

판별자가 사람처럼 “숫자 8의 윗부분을 둥글게 그려라”라고 언어로 지시하는 것은 아니다. 손실함수의 **기울기**가 가중치 수정 방향을 알려준다.

**구분:** 판별자를 학습하는 단계에서는 판별자의 가중치를 갱신하고, 생성자를 학습하는 단계에서는 판별자를 통해 기울기를 전달하되 생성자의 가중치를 갱신한다.

## 10. 생성자와 판별자 비교

| 구분 | 생성자 G | 판별자 D |
|---|---|---|
| 역할 | 숫자 이미지 생성 | 진짜·가짜 판별 |
| 입력 | 무작위 잠재벡터 100개 | 이미지 픽셀값 784개 |
| 출력 | 픽셀값 784개 | 판별값 1개 |
| 마지막 활성화 함수 | Tanh | Sigmoid |
| 학습 목표 | 진짜처럼 보이는 이미지 생성 | 진짜·가짜 구분 |
| 최적화 | 역전파 + Adam | 역전파 + Adam |

## 11. 핵심 요약 10문장

1. 판별자는 입력 이미지가 실제 MNIST 데이터인지 판단하는 신경망이다.
2. 28×28 흑백 이미지를 784개의 픽셀값으로 펼쳐 입력한다.
3. 첫 번째 은닉층은 784개 입력값을 512개 특징값으로 변환한다.
4. 두 번째 은닉층은 512개 값을 256개로 변환한다.
5. 은닉층에서는 LeakyReLU 활성화 함수를 사용한다.
6. 출력층은 256개 값을 하나의 판별 점수로 변환한다.
7. Sigmoid 함수는 판별 점수를 0~1 사이로 변환한다.
8. 실제 이미지의 정답은 1, 가짜 이미지의 정답은 0으로 설정한다.
9. BCELoss로 오차를 계산하고 역전파와 Adam으로 가중치를 수정한다.
10. **판별자는 생성자가 더 그럴듯한 이미지를 생성하도록 학습하는 데 필요한 기울기 정보를 제공한다.**

---

**결론:** 생성자는 숫자 이미지를 만들고, 판별자는 그 이미지가 실제 데이터에서 왔는지 판단한다. 두 신경망이 번갈아 학습하는 과정에서 생성자의 이미지 생성 능력이 향상될 수 있다.
