# 8단계. GAN 숫자 변환 — 잠재공간 보간 상세 해설

## 1. 숫자 변환이란?

**잠재공간 보간(Latent Space Interpolation)**은 두 잠재벡터 사이의 중간 벡터를 계산한 뒤, 학습된 생성자에 입력하여 숫자 이미지가 점진적으로 변하는 모습을 관찰하는 방법이다.

예를 들어 첫 벡터에서 숫자 3, 두 번째 벡터에서 숫자 8이 생성되었다면 중간 벡터에서 숫자의 획과 형태가 달라지는 모습을 볼 수 있다. **3→8은 설명을 위한 가상 사례이며 실제 생성 숫자는 지정되지 않는다.**

## 2. 7단계와 8단계 비교

| 구분 | 7단계 숫자 생성 | 8단계 숫자 변환 |
|---|---|---|
| 목적 | 새로운 숫자 이미지 생성 | 이미지의 연속적 변화 관찰 |
| 입력 | 독립적인 무작위 잠재벡터 16개 | 두 벡터 사이에서 보간한 벡터 12개 |
| 출력 | 숫자 이미지 16개 | 연속적으로 변화하는 이미지 12개 |
| 판별자·역전파·Adam | 사용하지 않음 | 사용하지 않음 |

## 3. 전체 Python 코드

```python
import torch
import matplotlib.pyplot as plt

# 학습된 생성자를 평가 모드로 전환
generator.eval()

# ① 시작·끝 잠재벡터 생성
z_start = torch.randn(1, latent_dim).to(device)
z_end = torch.randn(1, latent_dim).to(device)

# ② 12개 보간 위치 설정
num_steps = 12
alphas = torch.linspace(0, 1, num_steps).to(device)

# ③ 중간 잠재벡터 계산
interpolated_vectors = []
for alpha in alphas:
    z = (1 - alpha) * z_start + alpha * z_end
    interpolated_vectors.append(z)
interpolated_vectors = torch.cat(interpolated_vectors, dim=0)

# ④ 이미지 생성: 가중치 수정 없음
with torch.no_grad():
    generated_images = generator(interpolated_vectors)

# ⑤ 결과 표시
fig, axes = plt.subplots(1, num_steps, figsize=(15, 2))
for i, ax in enumerate(axes):
    img = generated_images[i].cpu().squeeze()
    img = (img + 1) / 2
    ax.imshow(img, cmap='gray', vmin=0, vmax=1)
    ax.set_title(f'{alphas[i].item():.2f}')
    ax.axis('off')
plt.tight_layout()
plt.show()
```

## 4. 핵심 수식: 선형 보간

$$
z(\alpha)=(1-\alpha)z_A+\alpha z_B
$$

- $z_A$: 시작 잠재벡터
- $z_B$: 끝 잠재벡터
- $\alpha$: 두 벡터의 혼합 비율(0~1)
- $z(\alpha)$: 계산된 중간 잠재벡터

$\alpha=0$이면 시작점, $\alpha=0.5$이면 중간점, $\alpha=1$이면 끝점이다. **이미지 픽셀을 섞는 것이 아니라 생성자에 입력할 잠재벡터를 섞는다.**

## 5. 실제 숫자로 계산하는 예시

100차원 대신 2차원 잠재벡터로 단순화한다.

$$z_A=(2,4),\qquad z_B=(8,10)$$

**① $\alpha=0$**

$$z(0)=1(2,4)+0(8,10)=(2,4)$$

**② $\alpha=0.25$**

$$z(0.25)=0.75(2,4)+0.25(8,10)=(3.5,5.5)$$

첫 번째 좌표: $0.75\times2+0.25\times8=3.5$  
두 번째 좌표: $0.75\times4+0.25\times10=5.5$

**③ $\alpha=0.5$**

$$z(0.5)=0.5(2,4)+0.5(8,10)=(5,7)$$

**④ $\alpha=1$**

$$z(1)=0(2,4)+1(8,10)=(8,10)$$

실제 GAN에서는 같은 계산을 **100차원의 모든 좌표**에 적용한다.

## 6. 왜 12단계인가?

`torch.linspace(0, 1, 12)`는 시작점과 끝점을 포함한 12개의 값을 생성한다. 따라서 간격은 11개이다.

$$\Delta\alpha=\frac{1}{12-1}=\frac{1}{11}\approx0.0909$$

| 단계 | $\alpha$ | 시작 벡터 비율 | 끝 벡터 비율 |
|---:|---:|---:|---:|
| 1 | 0.000 | 100.0% | 0.0% |
| 2 | 0.091 | 90.9% | 9.1% |
| 3 | 0.182 | 81.8% | 18.2% |
| 4 | 0.273 | 72.7% | 27.3% |
| 5 | 0.364 | 63.6% | 36.4% |
| 6 | 0.455 | 54.5% | 45.5% |
| 7 | 0.545 | 45.5% | 54.5% |
| 8 | 0.636 | 36.4% | 63.6% |
| 9 | 0.727 | 27.3% | 72.7% |
| 10 | 0.818 | 18.2% | 81.8% |
| 11 | 0.909 | 9.1% | 90.9% |
| 12 | 1.000 | 0.0% | 100.0% |

단계 수를 늘리면 변화를 더 촘촘히 관찰할 수 있지만 이미지 품질이 자동으로 좋아지는 것은 아니다.

## 7. 잠재벡터가 변하면 무엇이 달라지는가?

생성자는 다음 함수를 학습한다.

$$x=G_\theta(z)$$

잠재벡터 $z$가 달라지면 이미지의 획 굵기, 기울기, 곡선, 고리 크기, 숫자의 종류 등이 달라질 수 있다. 다만 특정 잠재벡터 좌표가 특정 특징 하나에 반드시 대응하는 것은 아니다. 또한 중간 이미지가 언제나 자연스럽거나 읽기 쉬운 숫자로 나타나는 것은 아니다.

## 8. 잠재공간 보간과 픽셀 보간의 차이

| 구분 | 픽셀 보간 | 잠재공간 보간 |
|---|---|---|
| 혼합 대상 | 완성된 이미지의 픽셀값 | 생성자 입력 잠재벡터 |
| 생성자 필요 여부 | 불필요 | 필요 |
| 중간 결과 | 두 이미지가 겹쳐 보일 수 있음 | 생성자가 새 이미지를 계산 |
| 한계 | 단순 혼합으로 보일 수 있음 | 중간 이미지 품질이 보장되지 않음 |

픽셀 보간은 두 그림을 투명하게 겹치는 것에 가깝고, 잠재공간 보간은 생성자가 학습한 이미지 생성 함수를 이용해 중간 이미지를 계산한다.

## 9. 가중치는 수정되는가?

**아니다.** 8단계는 학습된 생성자를 사용하는 추론 단계이다.

```python
with torch.no_grad():
    generated_images = generator(interpolated_vectors)
```

손실 계산, `backward()`, `optimizer.step()`을 수행하지 않는다. 생성자의 가중치 $\theta$는 고정하고 입력 벡터만 바꾼다.

$$G_\theta(z_1),\ G_\theta(z_2),\ \ldots,\ G_\theta(z_{12})$$

## 10. 핵심 요약 10문장

1. GAN 숫자 변환은 잠재공간 보간으로 이미지의 변화를 관찰하는 과정이다.
2. 먼저 100차원 무작위 잠재벡터 두 개를 생성한다.
3. 두 벡터 사이의 중간 벡터를 선형 보간으로 계산한다.
4. 보간 수식은 $z(\alpha)=(1-\alpha)z_A+\alpha z_B$이다.
5. $\alpha$는 시작·끝 벡터의 혼합 비율을 결정한다.
6. 12단계 보간은 시작점과 끝점을 포함해 12개 벡터를 만든다.
7. 각 벡터를 학습된 생성자에 입력해 이미지를 생성한다.
8. 벡터가 바뀌면 숫자의 형태, 굵기, 기울기, 종류 등이 달라질 수 있다.
9. 보간 단계에서는 판별자나 Adam을 사용하지 않고 가중치도 수정하지 않는다.
10. **잠재공간 보간은 학습된 이미지 표현 공간에서 두 지점 사이를 이동하며 생성 이미지의 변화를 관찰하는 방법이다.**

> **결론:** 7단계는 독립적인 무작위 벡터에서 숫자를 생성하고, 8단계는 두 벡터 사이를 이동하면서 숫자의 변화 과정을 관찰한다.
