# 5단계. GAN 손실 계산(Loss Calculation) 코드 상세 해설

## 1. 손실 계산의 목적

GAN은 **생성자(Generator, G)**와 **판별자(Discriminator, D)**가 서로 다른 목표로 학습한다.

- **판별자 손실:** 실제 MNIST 이미지를 진짜(1), 생성 이미지를 가짜(0)로 구분하지 못한 정도
- **생성자 손실:** 생성 이미지에 대해 판별자가 진짜(1)라고 판단하도록 만들지 못한 정도

예를 들어 생성자가 숫자 8처럼 보이는 가짜 이미지를 만들고 판별자가 `0.2`를 출력했다면, 판별자는 가짜를 비교적 잘 구분했지만 생성자는 판별자를 충분히 속이지 못했다.

## 2. 핵심 코드

```python
criterion = nn.BCELoss()

# 판별자의 실제 이미지 손실
real_output = discriminator(real_imgs)
d_real_loss = criterion(real_output, real_labels)

# 판별자의 가짜 이미지 손실
fake_output = discriminator(fake_imgs.detach())
d_fake_loss = criterion(fake_output, fake_labels)

# 판별자 전체 손실
d_loss = d_real_loss + d_fake_loss

# 생성자 손실: 가짜 이미지에 대해 목표 레이블 1 사용
fake_output = discriminator(fake_imgs)
g_loss = criterion(fake_output, real_labels)
```

`detach()`는 판별자를 학습하는 동안 가짜 이미지에서 생성자 쪽으로 기울기가 역전파되지 않도록 분리한다.

## 3. 이진 교차 엔트로피(BCELoss)

```python
criterion = nn.BCELoss()
```

BCELoss는 정답 레이블 `y`와 판별자 출력 `p` 사이의 오차를 계산한다.

$$
L=-\left[y\ln(p)+(1-y)\ln(1-p)\right]
$$

| 기호 | 의미 |
|---|---|
| $L$ | 손실값 |
| $y$ | 정답 레이블(0 또는 1) |
| $p$ | 판별자가 출력한 값(0~1) |
| $\ln$ | 자연로그 |

### 정답이 1일 때

$$
L=-\ln(p)
$$

`p`가 1에 가까울수록 손실이 작다.

### 정답이 0일 때

$$
L=-\ln(1-p)
$$

`p`가 0에 가까울수록 손실이 작다.

## 4. 판별자 손실 계산

### ① 실제 이미지 손실

```python
d_real_loss = criterion(real_output, real_labels)
```

실제 이미지의 정답은 1이다.

- 판별값 `0.9`: $L_{\mathrm{real}}=-\ln(0.9)\approx0.105$
- 판별값 `0.2`: $L_{\mathrm{real}}=-\ln(0.2)\approx1.609$

실제 이미지를 가짜라고 판단할수록 손실이 커진다.

### ② 가짜 이미지 손실

```python
d_fake_loss = criterion(fake_output, fake_labels)
```

가짜 이미지의 정답은 0이다.

가짜 이미지의 판별값이 `0.2`라면 다음과 같다.

$$
L_{\mathrm{fake}}=-\ln(1-0.2)=-\ln(0.8)\approx0.223
$$

### ③ 판별자 전체 손실

```python
d_loss = d_real_loss + d_fake_loss
```

$$
\boxed{L_D=L_{\mathrm{real}}+L_{\mathrm{fake}}}
$$

앞의 예시를 합하면 다음과 같다.

$$
L_D\approx0.105+0.223=0.328
$$

**주의:** PyTorch `nn.BCELoss()`는 기본적으로 배치 내 각 이미지의 손실을 평균한다. 이 코드는 실제 이미지 배치의 평균 손실과 가짜 이미지 배치의 평균 손실을 더한다.

## 5. 생성자 손실 계산

```python
fake_output = discriminator(fake_imgs)
g_loss = criterion(fake_output, real_labels)
```

생성 이미지가 가짜인데도 `real_labels`(1)를 사용하는 이유는 **생성자가 판별자를 속여 가짜 이미지를 진짜라고 판단하게 만드는 것**을 목표로 하기 때문이다.

$$
\boxed{L_G=-\ln(D(G(z)))}
$$

- $z$: 무작위 잠재벡터
- $G(z)$: 생성자가 만든 이미지
- $D(G(z))$: 그 이미지에 대한 판별자의 출력

예를 들어 가짜 이미지의 판별값이 `0.2`라면 생성자 손실은 다음과 같다.

$$
L_G=-\ln(0.2)\approx1.609
$$

반면 판별값이 `0.9`라면 다음과 같다.

$$
L_G=-\ln(0.9)\approx0.105
$$

현재 코드는 **비포화(non-saturating) GAN 생성자 손실**을 사용한다.

## 6. 같은 판별값에 대한 두 손실 비교

다음 표는 **가짜 이미지 한 장**에 대한 손실만 비교한 것이다. 판별자의 실제 이미지 손실은 포함하지 않았다.

| 가짜 이미지 판별값 $p$ | 판별자의 가짜 이미지 손실 $-\ln(1-p)$ | 생성자 손실 $-\ln(p)$ |
|---:|---:|---:|
| 0.1 | 0.105 | 2.303 |
| 0.3 | 0.357 | 1.204 |
| 0.5 | 0.693 | 0.693 |
| 0.7 | 1.204 | 0.357 |
| 0.9 | 2.303 | 0.105 |

**해석:** 같은 판별 결과라도 판별자와 생성자가 원하는 방향은 반대다. 판별자는 가짜 이미지에 대한 출력이 0에 가까워지기를, 생성자는 1에 가까워지기를 원한다.

## 7. 손실 계산에서 가중치 수정까지

손실값 자체가 가중치를 수정하는 것은 아니다. **손실함수를 미분하여 얻은 기울기**를 최적화 알고리즘이 사용한다.

```python
# 판별자 갱신
optimizer_D.zero_grad()
d_loss.backward()
optimizer_D.step()

# 생성자 갱신 (생성자 손실을 새로 계산한 뒤)
optimizer_G.zero_grad()
g_loss.backward()
optimizer_G.step()
```

| 명령어 | 역할 |
|---|---|
| `zero_grad()` | 이전 기울기 초기화 |
| `backward()` | 손실의 기울기 계산(역전파) |
| `step()` | Adam을 이용해 가중치 갱신 |

**학습 흐름 예시**

1. 생성자가 가짜 숫자 8을 생성한다.
2. 판별자가 가짜 이미지에 대해 `0.2`를 출력한다.
3. 생성자 손실이 약 `1.609`로 계산된다.
4. 역전파가 생성자의 가중치에 대한 기울기를 계산한다.
5. Adam이 생성자의 가중치를 수정한다.
6. 반복 학습을 통해 판별자가 더 진짜라고 판단하는 이미지를 만들도록 학습한다.

## 8. 두 손실이 모두 감소해야 할까?

반드시 그렇지는 않다. GAN은 두 신경망이 서로 반대되는 목표로 경쟁한다.

- **판별자 손실 감소:** 현재 생성 이미지와 실제 이미지를 더 잘 구분하고 있을 수 있다.
- **생성자 손실 감소:** 현재 판별자를 더 잘 속이고 있을 수 있다.
- **손실 진동:** 경쟁 학습에서 나타날 수 있는 현상이다.
- **판별값 0.5:** 판별자가 현재 이미지를 명확히 구분하지 못한다는 뜻이지, 생성 품질이 반드시 좋다는 증거는 아니다.

따라서 손실 그래프뿐 아니라 실제 생성된 숫자 이미지도 함께 관찰해야 한다.

## 9. 원래 GAN 목적함수와 현재 코드의 차이

원래 GAN의 대표적인 최소최대 목적함수는 다음과 같다.

$$
\min_G\max_D V(D,G)
$$

$$
V(D,G)=\mathbb{E}_{x\sim p_{\mathrm{data}}}[\ln D(x)]
+\mathbb{E}_{z\sim p_z}[\ln(1-D(G(z)))]
$$

현재 실습 코드의 생성자는 다음 비포화 손실을 최소화한다.

$$
L_G=-\mathbb{E}_{z\sim p_z}[\ln D(G(z))]
$$

이 방식은 생성자가 학습 초기에 매우 낮은 판별값을 받더라도 유용한 학습 신호를 얻기 쉽게 하는 대표적인 실용적 방법이다.

## 10. 핵심 요약 10문장

1. GAN의 손실 계산은 생성자와 판별자의 학습 목표 달성 정도를 평가한다.
2. 판별자와 생성자는 서로 다른 목표를 가진다.
3. 판별자는 실제 이미지에 정답 1, 가짜 이미지에 정답 0을 사용한다.
4. 생성자는 가짜 이미지에 대해 판별자가 1을 출력하도록 학습한다.
5. 두 신경망 모두 BCELoss를 사용한다.
6. 판별자 전체 손실은 실제 이미지 손실과 가짜 이미지 손실의 합이다.
7. 생성자 손실은 가짜 이미지의 판별값을 1에 가깝게 만드는 기준으로 계산한다.
8. 역전파는 기울기를 계산하고 Adam은 이를 이용하여 가중치를 수정한다.
9. GAN에서는 생성자와 판별자의 손실이 반드시 동시에 감소하지 않는다.
10. **GAN 손실함수의 핵심은 판별자의 진위 판단을 생성자의 학습 신호로 활용하는 것이다.**

---

**정리:** 4단계 경쟁 학습은 생성자와 판별자가 번갈아 학습하는 과정이며, 5단계 손실 계산은 각 신경망이 어떤 목표로 가중치를 수정하는지 정하는 수학적 기준이다.
