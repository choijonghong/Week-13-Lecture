# **🤖 GAN(Generative Adversarial Network) 코드 분석 가이드**

이 보고서는 MNIST(손글씨) 데이터를 생성하는 GAN 모델의 구조와 작동 원리를 입문자 수준에서 쉽게 분석한 내용입니다.

## **1\. GAN의 핵심 철학: "위조지폐범 vs 경찰"**

GAN의 모든 코드는 이 한 문장으로 요약됩니다. **"서로 속고 속이며 함께 성장한다."**

* **생성자(Generator):** 가짜 이미지를 만드는 위조지폐범. 경찰을 속이는 것이 최종 목표입니다.  
* **판별자(Discriminator):** 가짜를 잡아내는 경찰. 진짜 데이터와 가짜 데이터를 완벽히 구분하는 것이 목표입니다.

## **2\. 주요 코드 구성 요소 분석**

### **① 데이터 준비 (Data Loading)**

* **역할:** 모델에게 '진짜'가 무엇인지 알려주는 학습 자료를 준비합니다.  
* **대상:** MNIST 데이터셋 (0\~9까지의 손글씨 숫자 이미지).  
* **코드 흐름:** PyTorch의 torchvision을 사용하여 데이터를 불러오고 정규화합니다.

### **② 생성자(Generator) 모델 구조**

* **입력:** 아무 의미 없는 무작위 숫자(노이즈, Latent Vector).  
* **변환과정:** 여러 층의 선형 레이어(Linear Layer)를 거치며 숫자를 이미지의 픽셀값(28x28=784개)으로 확장합니다.  
* **출력:** 인공지능이 그린 '가짜' 숫자 이미지.

### **③ 판별자(Discriminator) 모델 구조**

* **입력:** 이미지 1장 (진짜일 수도, 생성자가 만든 가짜일 수도 있음).  
* **변환과정:** 이미지를 분석하여 0(가짜)에서 1(진짜) 사이의 확률 점수를 계산합니다.  
* **출력:** "이 이미지가 진짜일 확률은 00%입니다"라는 판단 결과.

## **3\. 학습 과정 (The Training Loop)의 2단계**

학습 루프는 아래의 두 과정이 무한 반복(Epoch)되는 구조입니다.

| 단계 | 목표 | 행동 |
| :---- | :---- | :---- |
| **1단계: 경찰 훈련** | 감별 능력 강화 | 진짜 이미지에는 '1'이라는 정답을, 가짜에는 '0'이라는 정답을 주고 공부하게 함. |
| **2단계: 위조범 훈련** | 속임수 능력 강화 | 자기가 만든 가짜를 경찰에게 주고, 경찰이 '1(진짜)'이라고 말하게끔 자신의 수법을 수정함. |

## **4\. 코드에서 꼭 알아야 할 수식: 손실 함수 (BCELoss)**

코드에 등장하는 BCELoss는 \*\*"정답과 얼마나 멀리 있는가"\*\*를 측정하는 척도입니다.

* **판별자**는 이 오차를 **최소화**하여 정답(0 또는 1)을 정확히 맞히려 합니다.  
* **생성자**는 판별자가 가짜를 진짜로 착각하게 만들어, 판별자의 오차를 **최대화**하는 방향으로 움직입니다.

## **5\. 최종 결과물**

학습이 끝난 후 코드는 matplotlib을 통해 결과를 보여줍니다.

* **초기:** 지직거리는 TV 화면 같은 노이즈만 보임.  
* **중기:** 숫자의 둥근 형태가 나타나기 시작함.  
* **후기:** 사람이 쓴 것과 구분이 안 될 정도의 선명한 숫자 이미지가 생성됨.

### **💡 분석 요약**

GAN 코드는 단순히 코딩 기술이 아니라 \*\*'경쟁을 통한 진화'\*\*라는 철학을 수학적으로 구현한 것입니다. 생성자는 판별자라는 '스승' 혹은 '라이벌'이 있기에 아무 의미 없는 숫자로부터 예술적인 결과물을 만들어낼 수 있습니다.
