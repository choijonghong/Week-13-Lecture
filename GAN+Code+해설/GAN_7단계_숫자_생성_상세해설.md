# 7단계. GAN 숫자 생성(Number Generation) 코드 상세 해설

## 1. 숫자 생성이란?

**GAN의 숫자 생성은 경쟁 학습을 마친 생성자(Generator)가 무작위 잠재벡터를 입력받아 실제 손글씨와 유사한 새로운 숫자 이미지를 만드는 과정**입니다.

- 4단계 경쟁 학습: 생성자와 판별자가 번갈아 학습합니다.
- 5단계 손실 계산: 각 신경망의 오차를 계산합니다.
- 6단계 가중치 최적화: 역전파와 Adam으로 가중치를 수정합니다.
- **7단계 숫자 생성: 학습된 생성자만 이용해 이미지를 생성합니다.**

숫자 생성 단계에서는 판별자, 손실 계산, 역전파, Adam을 실행할 필요가 없습니다.

## 2. 숫자 생성 코드

아래는 제공된 GAN 코드의 숫자 생성 부분을 설명하기 위해 정리한 예시입니다.

```python
# 학습된 생성자를 평가 모드로 전환
generator.eval()

# 새로운 숫자 이미지 16개 생성
num_images = 16

# 100차원 무작위 잠재벡터 16개 생성
new_noise = torch.randn(num_images, latent_dim).to(device)

# 기울기 계산 없이 이미지 생성
with torch.no_grad():
    generated_images = generator(new_noise)

# 이미지 출력
fig, axes = plt.subplots(4, 4, figsize=(6, 6))

for i, ax in enumerate(axes.flat):
    img = generated_images[i].cpu().squeeze()
    img = (img + 1) / 2
    ax.imshow(img, cmap="gray")
    ax.axis("off")

plt.tight_layout()
plt.show()
```

이 코드는 100차원 잠재벡터 16개를 생성자에 입력하여 16개의 손글씨 숫자 이미지를 출력합니다. `generator`, `latent_dim`, `device`와 `plt` 등은 앞선 셀에서 정의되거나 불러와져 있어야 합니다.

## 3. 숫자 생성의 전체 과정

1. `torch.randn()`으로 무작위 잠재벡터를 생성합니다.
2. 학습된 생성자에 잠재벡터를 입력합니다.
3. 생성자가 각 벡터를 784개의 픽셀값으로 변환합니다.
4. 784개 값을 28×28 흑백 이미지로 재배열합니다.
5. 픽셀값을 화면 표시 범위로 변환하고 이미지를 출력합니다.

생성자의 신경망 구조는 **100 → 256 → 512 → 1,024 → 784**입니다.

## 4. 코드별 상세 해설

### ① `generator.eval()` — 평가 모드 전환

```python
generator.eval()
```

생성자를 평가 모드로 전환합니다. Dropout이나 Batch Normalization 같은 층은 평가 모드에서 동작이 달라질 수 있습니다. 현재 생성자는 `Linear`, `LeakyReLU`, `Tanh`로 구성되어 있으므로 `eval()` 자체가 출력 계산 방식을 바꾸지는 않습니다.

### ② `num_images = 16` — 생성할 이미지 개수

```python
num_images = 16
```

한 번에 16장의 이미지를 생성하도록 설정합니다. 100장으로 변경하려면 출력 화면 구성도 함께 조정해야 합니다.

### ③ `torch.randn()` — 무작위 잠재벡터 생성

```python
new_noise = torch.randn(num_images, latent_dim).to(device)
```

`latent_dim = 100`이므로, 100개 값으로 이루어진 벡터를 16개 만듭니다. `torch.randn()`은 평균 0, 표준편차 1인 표준정규분포에서 값을 추출합니다.

$$
z \sim \mathcal{N}(0,I)
$$

예를 들어 한 잠재벡터의 앞부분은 `[0.42, -1.18, 0.73, 0.05, ...]`와 같을 수 있습니다. **무작위로 선택되는 것은 숫자 0~9의 레이블이 아니라 잠재벡터의 값**입니다.

### ④ `generator(new_noise)` — 이미지 생성

```python
with torch.no_grad():
    generated_images = generator(new_noise)
```

생성자는 학습된 가중치를 이용하여 잠재벡터를 이미지로 변환합니다.

$$
x_{\mathrm{fake}} = G_{\theta}(z)
$$

- $z$: 무작위 잠재벡터
- $G_{\theta}$: 학습된 가중치 $\theta$를 가진 생성자
- $x_{\mathrm{fake}}$: 생성된 숫자 이미지

`torch.no_grad()`는 역전파용 계산 그래프를 기록하지 않아 메모리를 절약합니다. 이 단계에서는 가중치를 학습하지 않습니다.

## 5. 생성 이미지의 크기와 형태

생성자의 출력 텐서는 `(16, 1, 28, 28)`입니다.

| 차원 | 값 | 의미 |
|---|---:|---|
| 첫 번째 | 16 | 이미지 개수 |
| 두 번째 | 1 | 흑백 채널 |
| 세 번째 | 28 | 이미지 높이 |
| 네 번째 | 28 | 이미지 너비 |

따라서 **28×28 흑백 이미지 16장**이 생성됩니다.

## 6. 화면 표시를 위한 픽셀값 변환

```python
img = (img + 1) / 2
```

생성자의 마지막 `Tanh()`는 -1부터 1 사이의 값을 출력합니다. 화면 표시를 위해 0부터 1 사이로 바꿉니다.

$$
x_{\mathrm{display}} = \frac{x_{\mathrm{generated}}+1}{2}
$$

| 생성자 출력값 | 화면 표시값 |
|---:|---:|
| -1 | 0 |
| -0.5 | 0.25 |
| 0 | 0.5 |
| 0.5 | 0.75 |
| 1 | 1 |

이 변환은 가중치를 수정하지 않으며 이미지를 보기 좋게 표시하기 위한 처리입니다.

## 7. 생성되는 숫자를 사람이 지정하는가?

**현재 코드는 특정 숫자 레이블을 지정하지 않습니다.** 예를 들어 숫자 8을 입력하여 8을 그리도록 지시하는 구조가 아닙니다.

```python
z = torch.randn(1, 100).to(device)

with torch.no_grad():
    image = generator(z)
```

생성 결과가 8, 3, 5 등으로 보일 수 있지만 어떤 숫자가 나올지 직접 제어하지는 않습니다. 숫자 종류를 명시적으로 제어하려면 조건부 GAN(cGAN) 같은 별도 구조가 필요합니다.

## 8. 같은 잠재벡터를 입력하면 같은 이미지가 나오는가?

가중치와 연산 조건이 같다면 동일한 잠재벡터에 대해 동일한 이미지가 생성됩니다.

```python
z = torch.randn(1, 100).to(device)

with torch.no_grad():
    image_1 = generator(z)
    image_2 = generator(z)
```

현재 생성자 구조에서는 `image_1`과 `image_2`의 값이 같습니다. 새로운 잠재벡터를 입력하면 다른 이미지가 생성될 수 있습니다.

## 9. 실제 MNIST 숫자를 복사하는 것인가?

생성자는 MNIST 이미지 한 장을 단순히 골라서 출력하지 않습니다. 학습 과정에서 데이터의 특징과 분포를 반영하도록 가중치를 학습하고, 잠재벡터로부터 이미지를 계산합니다.

다만 **새로운 잠재벡터에서 생성했다는 사실만으로 훈련 이미지를 암기하지 않았다고 증명할 수는 없습니다.** 암기 여부는 별도의 검증이 필요합니다.

## 10. 경쟁 학습과 숫자 생성의 차이

| 구분 | 경쟁 학습 | 숫자 생성 |
|---|---|---|
| 목적 | 생성 능력 학습 | 새로운 이미지 생성 |
| 생성자 | 사용 | 사용 |
| 판별자 | 사용 | 사용하지 않음 |
| 손실함수 | 계산 | 계산하지 않음 |
| 역전파 | 수행 | 수행하지 않음 |
| Adam | 가중치 수정 | 사용하지 않음 |

**경쟁 학습은 숫자를 잘 그리는 방법을 배우는 과정이고, 숫자 생성은 배운 능력을 사용하는 과정**입니다.

## 11. 생성 결과 해석

학습이 잘 진행되었다면 생성된 숫자에서 손글씨 특유의 곡선, 기울기, 획의 굵기 등을 관찰할 수 있습니다. 그러나 모든 생성 이미지가 반드시 명확한 숫자로 보이는 것은 아닙니다. 생성 결과는 학습 상태와 입력 잠재벡터에 따라 달라집니다.

## 12. 핵심 요약 10문장

1. 숫자 생성은 학습된 생성자로 새로운 손글씨 이미지를 만드는 과정입니다.
2. 생성자에는 숫자 레이블이 아니라 100차원 무작위 잠재벡터를 입력합니다.
3. `torch.randn()`은 표준정규분포에서 무작위 값을 생성합니다.
4. 생성자는 학습된 가중치를 이용해 잠재벡터를 이미지 픽셀값으로 변환합니다.
5. 생성자의 출력은 28×28 크기의 흑백 이미지입니다.
6. 이 코드에서는 한 번에 16개의 숫자 이미지를 생성합니다.
7. Tanh 출력값을 화면에 표시하기 위해 -1~1 범위에서 0~1 범위로 변환합니다.
8. 같은 잠재벡터와 같은 가중치를 사용하면 같은 이미지가 생성됩니다.
9. 숫자 생성 단계에서는 판별자, 손실함수, 역전파, Adam을 사용하지 않습니다.
10. **GAN의 숫자 생성은 경쟁 학습으로 획득한 생성 능력을 이용하여 잠재벡터를 손글씨와 유사한 이미지로 변환하는 과정입니다.**
