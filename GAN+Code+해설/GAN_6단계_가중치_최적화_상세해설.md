# 6단계. GAN 가중치 최적화(Weight Optimization) 상세 해설

## 1. 가중치 최적화란?

GAN의 가중치 최적화는 **생성자와 판별자가 각각의 손실함수를 줄이기 위해 신경망 내부의 가중치와 편향을 반복적으로 수정하는 과정**이다.

- **4단계 경쟁 학습:** 생성자와 판별자가 서로 다른 목표로 번갈아 학습한다.
- **5단계 손실 계산:** 각 신경망의 예측이 학습 목표와 얼마나 다른지 계산한다.
- **6단계 가중치 최적화:** 손실을 미분하여 얻은 기울기를 이용해 매개변수를 실제로 수정한다.

이 코드에서는 **Adam(Adaptive Moment Estimation, 적응적 모멘트 추정)** 최적화 알고리즘을 사용한다.

## 2. 가중치 최적화 코드

```python
optimizer_G = torch.optim.Adam(generator.parameters(), lr=0.0002)
optimizer_D = torch.optim.Adam(discriminator.parameters(), lr=0.0002)

# 판별자 가중치 최적화
optimizer_D.zero_grad()
d_loss.backward()
optimizer_D.step()

# 생성자 가중치 최적화
optimizer_G.zero_grad()
g_loss.backward()
optimizer_G.step()
```

생성자와 판별자는 **각각 독립된 Adam 최적화 객체**를 사용한다. 실제 학습 루프에서는 각 손실을 계산한 다음 해당 역전파와 업데이트를 실행한다.

## 3. 최적화 과정의 다섯 단계

1. **순전파(Forward):** 생성자 또는 판별자가 출력을 계산한다.
2. **손실 계산(Loss):** 출력이 학습 목표와 얼마나 다른지 평가한다.
3. **역전파(Backward):** 각 가중치에 대한 손실의 기울기를 계산한다.
4. **Adam 계산:** 기울기의 지수이동평균과 제곱의 지수이동평균을 계산한다.
5. **가중치 갱신(Step):** 계산한 수정량을 매개변수에 적용한다.

## 4. `parameters()`의 의미

```python
generator.parameters()
discriminator.parameters()
```

각 신경망의 학습 가능한 **가중치와 편향**을 최적화 알고리즘에 전달한다.

예를 들어 생성자의 첫 번째 선형층은 다음과 같다.

```python
nn.Linear(100, 256)
```

- 가중치: $100\times256=25,600$개
- 편향: $256$개
- 합계: $25,856$개

앞서 설명한 신경망 구조를 기준으로 전체 학습 가능한 매개변수 수는 다음과 같다.

| 신경망 | 매개변수 수 |
|---|---:|
| 생성자 G | 1,485,328개 |
| 판별자 D | 533,505개 |
| **합계** | **2,018,833개** |

사람이 약 202만 개의 매개변수를 하나씩 수정하는 것이 아니라, 역전파와 Adam이 자동으로 계산한다.

## 5. `zero_grad()` — 이전 기울기 초기화

```python
optimizer_G.zero_grad()
```

PyTorch에서는 기본적으로 기울기가 누적되므로 새로운 학습 단계에서 이전 기울기를 초기화한다.

**예시:** 이전 기울기가 0.3이고 새로운 기울기가 0.2라면 초기화하지 않을 경우 0.5로 누적될 수 있다. `zero_grad()`는 의도하지 않은 누적을 방지한다.

## 6. `backward()` — 역전파로 기울기 계산

```python
g_loss.backward()
```

역전파는 손실함수를 각 가중치에 대해 미분한다.

$$
g_t=\frac{\partial L}{\partial w_t}
$$

- $g_t$: 현재 단계의 기울기
- $L$: 손실함수
- $w_t$: 가중치

예를 들어 $\partial L/\partial w=0.8$이라면 해당 가중치를 증가시키는 방향으로 손실이 증가하므로, 경사하강법은 가중치를 감소시키는 방향으로 이동한다. 기울기가 $-0.8$이라면 반대 방향이다.

## 7. Adam 알고리즘의 핵심 원리

일반 경사하강법은 다음과 같이 가중치를 수정한다.

$$
w_t=w_{t-1}-\alpha g_t
$$

Adam은 현재 기울기뿐 아니라 **기울기의 1차 및 2차 모멘트 추정치**를 함께 활용한다.

### 7.1 1차 모멘트: 기울기의 지수이동평균

$$
m_t=\beta_1m_{t-1}+(1-\beta_1)g_t
$$

- 일반적인 기본값: $\beta_1=0.9$
- 최근 기울기의 방향과 크기를 반영하는 이동평균이다.

### 7.2 2차 모멘트: 기울기 제곱의 지수이동평균

$$
v_t=\beta_2v_{t-1}+(1-\beta_2)g_t^2
$$

- 일반적인 기본값: $\beta_2=0.999$
- 기울기의 크기를 고려하여 매개변수별 업데이트를 조절하는 데 활용한다.

### 7.3 편향 보정

이동평균이 0에서 시작하므로 초기 편향을 보정한다.

$$
\hat m_t=\frac{m_t}{1-\beta_1^t}
$$

$$
\hat v_t=\frac{v_t}{1-\beta_2^t}
$$

### 7.4 최종 가중치 수정

$$
\boxed{w_t=w_{t-1}-\alpha\frac{\hat m_t}{\sqrt{\hat v_t}+\epsilon}}
$$

| 기호 | 의미 |
|---|---|
| $w_t$ | 수정 후 가중치 |
| $w_{t-1}$ | 수정 전 가중치 |
| $\alpha$ | 학습률(이 코드에서는 0.0002) |
| $\hat m_t$ | 편향 보정된 1차 모멘트 |
| $\hat v_t$ | 편향 보정된 2차 모멘트 |
| $\epsilon$ | 0으로 나누는 문제를 방지하는 작은 수 |

## 8. 실제 숫자로 계산하는 첫 번째 Adam 업데이트

다음 조건을 가정한다.

- 초기 가중치: $w_0=0.5000$
- 첫 기울기: $g_1=4$
- 학습률: $\alpha=0.0002$
- $\beta_1=0.9$, $\beta_2=0.999$
- $m_0=v_0=0$

**① 1차 모멘트**

$$
m_1=0.9(0)+0.1(4)=0.4
$$

**② 2차 모멘트**

$$
v_1=0.999(0)+0.001(4^2)=0.016
$$

**③ 편향 보정**

$$
\hat m_1=\frac{0.4}{1-0.9}=4
$$

$$
\hat v_1=\frac{0.016}{1-0.999}=16
$$

**④ 가중치 수정**

$$
w_1=0.5-0.0002\frac{4}{\sqrt{16}+\epsilon}
$$

$\epsilon$이 매우 작다고 보면 다음과 같다.

$$
\boxed{w_1\approx0.4998}
$$

즉, 이 단순화된 예시에서 가중치는 **0.5000 → 0.4998**로 감소한다.

## 9. 학습률이 가중치 수정에 미치는 영향

위의 **첫 번째 Adam 업데이트 예시**에서 $\epsilon$을 무시하면, 수정량은 학습률과 거의 같다.

| 학습률 | 수정량 | 수정 후 가중치 |
|---:|---:|---:|
| 0.0001 | 0.0001 | 0.4999 |
| **0.0002** | **0.0002** | **0.4998** |
| 0.001 | 0.001 | 0.4990 |
| 0.01 | 0.01 | 0.4900 |

학습률이 크다고 항상 더 빨리 좋은 결과를 얻는 것은 아니다. 너무 큰 학습률은 GAN 학습을 불안정하게 만들 수 있다.

## 10. 생성자와 판별자의 최적화 차이

| 구분 | 판별자 D | 생성자 G |
|---|---|---|
| 학습 목표 | 실제와 가짜 구분 | 가짜를 진짜처럼 생성 |
| 손실 | 실제·가짜 구분 손실 | 생성자 손실 |
| 역전파 | 판별자 매개변수 기울기 | 판별자를 통과하여 생성자까지 전달되는 기울기 |
| 최적화 객체 | `optimizer_D` | `optimizer_G` |
| 수정 대상 | 판별자 매개변수 | 생성자 매개변수 |

판별자 학습에서는 `fake_imgs.detach()`를 사용하여 생성자 쪽으로 기울기가 전달되지 않게 한다. 생성자 학습에서는 판별자를 통과한 기울기를 이용하지만, `optimizer_G.step()`이 갱신하는 것은 생성자 매개변수이다.

## 11. Adam을 사용하면 GAN이 반드시 잘 학습되는가?

**그렇지 않다.** Adam은 효율적인 최적화 알고리즘이지만 GAN의 안정적인 학습을 보장하지 않는다.

- 판별자가 지나치게 강해져 생성자의 학습이 어려워질 수 있다.
- 생성자가 비슷한 숫자만 반복해서 만드는 **모드 붕괴(Mode Collapse)**가 발생할 수 있다.
- 생성자와 판별자의 손실이 진동할 수 있다.

따라서 학습률과 배치 크기뿐 아니라 **실제 생성 이미지의 품질과 다양성**도 함께 확인해야 한다.

## 12. 요약하면,

1. 가중치 최적화는 손실을 줄이도록 신경망 매개변수를 수정하는 과정이다.
2. GAN의 생성자와 판별자는 각각 독립된 Adam 최적화 객체를 사용한다.
3. `parameters()`는 최적화할 가중치와 편향을 지정한다.
4. `zero_grad()`는 이전 학습 단계의 기울기를 초기화한다.
5. `backward()`는 역전파로 가중치별 손실 기울기를 계산한다.
6. `step()`은 Adam으로 가중치를 실제 수정한다.
7. Adam의 1차 모멘트는 기울기의 지수이동평균이다.
8. Adam의 2차 모멘트는 기울기 제곱의 지수이동평균이다.
9. Adam은 편향 보정과 매개변수별 수정량 조절을 수행한다.
10. **GAN의 가중치 최적화는 판별 능력과 생성 능력을 각각 개선하도록 매개변수를 반복적으로 수정하는 과정이다.**

> **핵심 결론:** 손실함수가 학습 목표를 정의하고, 역전파가 수정 방향을 계산하며, Adam이 실제 가중치를 변경한다.
