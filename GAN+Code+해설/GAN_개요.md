# GAN 코드의 개요 및 핵심 요약

## 1. 코드의 목적

**MNIST 손글씨 숫자 데이터를 이용하여 GAN을 학습한 후, 새로운 숫자 이미지를 생성하고 두 숫자 이미지 사이의 점진적인 변화 과정을 관찰하는 실습 코드이다.**

GAN(Generative Adversarial Network, 생성적 적대 신경망)은 생성자와 판별자가 경쟁적으로 학습하여 실제 손글씨와 유사한 이미지를 생성한다.

## 2. 코드의 주요 구성

| 단계 | 주요 내용 | 역할 |
|---|---|---|
| ① 데이터 준비 | MNIST 숫자 0~9 | 손글씨 이미지 60,000장 학습 준비 |
| ② 생성자 구성 | Generator | 무작위 잠재벡터로 가짜 숫자 이미지 생성 |
| ③ 판별자 구성 | Discriminator | 실제 숫자와 생성 숫자 구분 |
| ④ 경쟁 학습 | 100에포크 | 생성자와 판별자의 가중치 번갈아 수정 |
| ⑤ 손실 계산 | BCELoss | 두 신경망의 학습 손실 계산 |
| ⑥ 가중치 최적화 | Adam | 역전파로 구한 기울기를 이용해 가중치 수정 |
| ⑦ 숫자 생성 | 16개 이미지 | 학습된 생성자로 새로운 숫자 이미지 출력 |
| ⑧ 숫자 변환 | 12단계 보간 | 두 잠재벡터 사이의 이미지 변화 출력 |
| ⑨ 잠재벡터 혼합 | 두 벡터 결합 | 새로운 숫자 이미지 생성 실험 |

## 3. GAN의 핵심 작동 원리

**무작위 잠재벡터 → 생성자(G) → 가짜 숫자 이미지 → 판별자(D) → 진짜/가짜 판단 → 손실 계산 및 역전파**

- **생성자:** 판별자가 가짜 이미지를 진짜로 판단하도록 이미지를 생성한다.
- **판별자:** 실제 MNIST 이미지와 생성 이미지의 차이를 구분하도록 학습한다.
- **경쟁 학습:** 두 신경망이 각자의 손실을 줄이도록 가중치를 번갈아 수정한다.
- **학습 결과:** 생성자는 실제 손글씨와 유사한 숫자 이미지를 생성할 수 있게 된다.

## 4. 핵심 실습 과제

**GAN 학습 후 두 개의 무작위 잠재벡터를 선택하고, 그 사이를 12단계로 보간하여 숫자 이미지가 점진적으로 변화하는 과정을 출력한다.**

예를 들어 첫 잠재벡터가 숫자 3처럼 보이는 이미지를, 두 번째 잠재벡터가 숫자 8처럼 보이는 이미지를 생성했다면, 두 이미지 사이의 중간 형태를 관찰할 수 있다.

다만 **현재 코드는 3과 8을 사람이 직접 지정하지 않는다.** 시작과 종료 이미지는 무작위 잠재벡터 및 학습된 생성자에 따라 정해진다.

### 과제 수행 절차

1. MNIST 데이터로 GAN을 100에포크 학습한다.
2. 생성자와 판별자의 손실 변화를 확인한다.
3. 학습된 생성자로 새로운 숫자 이미지 16개를 출력한다.
4. 서로 다른 두 잠재벡터를 선택하여 12단계 보간 이미지를 출력한다.
5. 숫자의 형태가 어떻게 변화하는지 분석하고 잠재공간 보간의 의미를 설명한다.

## 5. 핵심 요약 5문장

1. GAN은 생성자와 판별자가 경쟁하면서 학습하는 생성형 인공지능이다.
2. 생성자는 무작위 잠재벡터를 이용하여 새로운 손글씨 숫자 이미지를 생성한다.
3. 판별자는 진짜와 가짜를 구분하며, 그 판단 결과는 생성자의 학습에 활용된다.
4. 학습이 완료되면 생성자는 판별자 없이도 새로운 숫자 이미지를 생성할 수 있다.
5. **이 코드의 핵심 과제는 경쟁 학습으로 획득한 생성 능력을 활용하여 숫자 이미지가 점진적으로 변화하는 과정을 관찰하는 것이다.**
