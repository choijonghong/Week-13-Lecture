# 2단계. GAN 생성자(Generator) 구성 코드 상세 해설

## 1. 생성자의 역할

**생성자(Generator)**는 100차원 무작위 잠재벡터를 입력받아 28×28 크기의 손글씨 숫자 이미지를 생성하는 신경망이다. 초기에는 숫자답지 않은 이미지를 만들 수 있지만, 판별자와의 경쟁 학습을 통해 실제 MNIST 손글씨와 유사한 이미지를 생성하도록 가중치가 수정된다.

> 현재 코드는 숫자 3이나 8의 레이블을 직접 입력하지 않는다. 어떤 숫자가 생성될지는 학습된 생성자와 무작위 잠재벡터에 따라 달라진다.

## 2. 실제 생성자 코드

```python
class Generator(nn.Module):
    def __init__(self):
        super(Generator, self).__init__()
        self.model = nn.Sequential(
            nn.Linear(latent_dim, 256),
            nn.LeakyReLU(0.2),
            nn.Linear(256, 512),
            nn.LeakyReLU(0.2),
            nn.Linear(512, 1024),
            nn.LeakyReLU(0.2),
            nn.Linear(1024, 28 * 28),
            nn.Tanh()
        )

    def forward(self, z):
        img = self.model(z)
        img = img.view(img.size(0), 1, 28, 28)
        return img
```

이 코드를 실행하려면 앞에서 `import torch`, `import torch.nn as nn`을 수행하고 `latent_dim = 100`을 설정해야 한다.

## 3. 생성자 신경망의 전체 구조

**100차원 잠재벡터 → 256 → 512 → 1,024 → 784개 픽셀값 → 1×28×28 흑백 이미지**

| 단계 | 입력 크기 | 출력 크기 | 역할 |
|---|---:|---:|---|
| 입력 | 100 | 100 | 무작위 잠재벡터 |
| 선형층 1 | 100 | 256 | 특징 표현 변환 |
| 선형층 2 | 256 | 512 | 특징 표현 확장 |
| 선형층 3 | 512 | 1,024 | 복합 특징 조합 |
| 출력층 | 1,024 | 784 | 픽셀값 생성 |
| 형태 변환 | 784 | 1×28×28 | 흑백 이미지 구성 |

뉴런 수가 늘어나는 것은 중간 특징 벡터의 차원이 늘어나는 것이지 이미지 해상도가 매 층마다 증가한다는 뜻은 아니다.

## 4. 코드별 상세 해설

### ① 생성자 클래스와 초기화

```python
class Generator(nn.Module):
    def __init__(self):
        super(Generator, self).__init__()
```

- `class Generator`: 생성자 신경망 클래스 정의
- `nn.Module`: PyTorch 신경망의 기본 클래스
- `__init__`: 생성자 객체를 만들 때 층을 초기화하는 함수
- `super(...)`: 부모 클래스의 초기화 수행
- `nn.Sequential`: 층을 나열한 순서대로 실행

### ② 첫 번째 선형층: 100 → 256

```python
nn.Linear(latent_dim, 256),
nn.LeakyReLU(0.2),
```

$$
h_1=\operatorname{LeakyReLU}(W_1z+b_1)
$$

- $z$: 100차원 입력 잠재벡터
- $W_1$: 학습되는 가중치 행렬
- $b_1$: 편향
- $h_1$: 256차원 출력

**예시:** 무작위 숫자 100개를 입력하면 각 뉴런이 가중합과 활성화 함수를 계산하여 새로운 값 256개를 만든다. 이 값들은 아직 이미지가 아닌 내부 특징 표현이다.

### ③ 두 번째 선형층: 256 → 512

```python
nn.Linear(256, 512),
nn.LeakyReLU(0.2),
```

$$
h_2=\operatorname{LeakyReLU}(W_2h_1+b_2)
$$

앞선 층의 특징들을 결합하여 512차원 표현을 만든다. 학습이 진행되면 곡선, 획의 굵기, 기울기 등과 관련된 정보가 분산된 형태로 표현될 수 있다. 단, 특정 뉴런 하나가 반드시 특정 특징 하나만 담당하는 것은 아니다.

### ④ 세 번째 선형층: 512 → 1,024

```python
nn.Linear(512, 1024),
nn.LeakyReLU(0.2),
```

$$
h_3=\operatorname{LeakyReLU}(W_3h_2+b_3)
$$

앞선 층에서 얻은 특징을 더욱 다양한 방식으로 조합한다. 아직 이미지 자체를 출력하는 단계는 아니다.

### ⑤ 출력층: 1,024 → 784

```python
nn.Linear(1024, 28 * 28),
nn.Tanh()
```

$$
28\times28=784
$$

최종 출력 784개는 이미지의 각 픽셀값에 대응한다. `Tanh()`는 출력값을 -1부터 1 사이로 제한한다. 이는 1단계에서 실제 MNIST 이미지를 같은 범위로 정규화한 것과 연결된다.

## 5. LeakyReLU 활성화 함수

```python
nn.LeakyReLU(0.2)
```

$$
f(x)=\begin{cases}x & x\geq0\\0.2x & x<0\end{cases}
$$

| 입력 $x$ | 출력 $f(x)$ |
|---:|---:|
| -5 | -1.0 |
| -2 | -0.4 |
| 0 | 0 |
| 2 | 2 |
| 5 | 5 |

음수 입력도 작은 기울기를 유지하므로 일반 ReLU에서 발생할 수 있는 뉴런 비활성화 문제를 완화하는 데 도움이 된다.

## 6. `forward()` 함수: 이미지 완성

```python
def forward(self, z):
    img = self.model(z)
    img = img.view(img.size(0), 1, 28, 28)
    return img
```

1. `self.model(z)`: 100차원 잠재벡터를 통과시켜 784개 픽셀값을 계산한다.
2. `img.view(...)`: 픽셀값을 `(이미지 개수, 1, 28, 28)` 형태로 재배열한다.
3. `return img`: 생성한 이미지 텐서를 반환한다.

예를 들어 16개의 잠재벡터를 입력하면 출력 텐서의 크기는 `(16, 1, 28, 28)`이다. 여기서 16은 이미지 개수, 1은 흑백 채널 수이다.

## 7. 생성자에 실제 숫자 3이나 8을 입력하는가?

**아니다.** 현재 모델은 숫자 레이블을 조건으로 입력받지 않는 일반 GAN이다.

```python
z = torch.randn(16, 100).to(device)
generated_imgs = generator(z)
```

이 코드는 정규분포에서 100차원 잠재벡터 16개를 추출한 다음 이미지 16개를 생성한다. 결과가 3, 8, 4, 9 등으로 보일 수 있지만 숫자를 직접 지정하지는 않는다.

## 8. 생성자 가중치는 어떻게 학습되는가?

1. 생성자가 무작위 잠재벡터로 가짜 숫자 이미지를 만든다.
2. 판별자가 해당 이미지가 진짜일 가능성을 평가한다.
3. 생성자는 판별자가 가짜를 진짜로 판단하도록 하는 손실을 계산한다.
4. 역전파로 생성자 가중치에 대한 기울기를 계산한다.
5. Adam 최적화 알고리즘이 생성자 가중치를 수정한다.
6. 이러한 경쟁 학습을 반복하며 생성 품질 개선을 시도한다.

**중요:** 생성자 구조를 정의하는 것만으로 숫자를 잘 생성하는 것은 아니다. 경쟁 학습을 거쳐 가중치를 조정해야 한다.

## 9. 핵심 요약 10문장

1. 생성자는 무작위 잠재벡터를 숫자 이미지로 변환하는 신경망이다.
2. 입력은 정규분포에서 추출한 100차원 잠재벡터이다.
3. 첫 번째 선형층은 100개의 값을 256개로 변환한다.
4. 두 번째 선형층은 256개를 512개로 변환한다.
5. 세 번째 선형층은 512개를 1,024개로 변환한다.
6. 각 은닉층에는 LeakyReLU 활성화 함수를 사용한다.
7. 출력층은 1,024개를 784개의 픽셀값으로 변환한다.
8. Tanh 함수는 출력값을 -1부터 1 사이로 제한한다.
9. `forward()` 함수는 784개의 값을 28×28 흑백 이미지 형태로 재배열한다.
10. 생성자는 판별자와의 경쟁 학습을 통해 실제 손글씨와 유사한 새로운 숫자를 생성하는 능력을 학습한다.
